# 📘 Day 09 - Dictionary in Python

## 📖 Overview

A Dictionary is one of the most powerful built-in data structures in Python. It stores data in the form of **key-value pairs**, allowing fast lookup, insertion, update, and deletion of data.

Unlike lists and tuples, dictionaries are **unordered (before Python 3.7)** and **ordered (Python 3.7+)**, mutable, and do not allow duplicate keys.
